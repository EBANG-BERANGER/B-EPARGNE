Confidentialité

Dernière mise à jour : 13 septembre 2026.

Béranger Épargne est une application de suivi de finances personnelles. Elle est conçue pour ne rien envoyer en dehors de votre appareil.

Quelles données sont enregistrées

Les entrées et sorties d'argent que vous saisissez (montant, catégorie, motif, date) sont stockées uniquement dans le stockage local de votre navigateur ou de l'application installée sur votre appareil.

Où vont ces données

  • Nulle part. L'application ne possède pas de serveur : aucune donnée n'est transmise, vendue ou partagée avec qui que ce soit.
  • Aucun outil d'analyse, de publicité ou de suivi n'est intégré.
  • Si vous désinstallez l'application ou effacez les données du navigateur pour ce site, l'historique est supprimé de façon définitive — utilisez la fonction Exporter pour en garder une copie de sauvegarde.

Contrôle de vos données

  • Exporter : télécharge une copie complète de votre registre au format JSON, que vous seul possédez.
  • Importer : recharge une copie précédemment exportée, par exemple sur un nouvel appareil.
  • Supprimer : effacer les données de l'application depuis les réglages de votre navigateur ou de votre appareil supprime définitivement le registre.
